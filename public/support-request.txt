ОБРАЩЕНИЕ В ПОДДЕРЖКУ POEHALI.DEV
Проект: dodelay.ru

Тема: статические страницы не отдаются по адресам без /index.html


СУТЬ ПРОБЛЕМЫ

Проект собирает статические HTML-страницы в подпапки (пререндер, 303 страницы).
Файлы на сервере есть и они корректные, но по обычному адресу сервер отдаёт
корневой index.html вместо нужного файла.

Проверка (реальные ответы сервера прямо сейчас):

  /podrabotka/yaroslavl
     без index.html: "Доделай.ру — шабашка и подработка в Ярославле"   ← главная
     с index.html:   "Подработка в Ярославле: цены, районы, мастера"   ← верно

  /podrabotka/rybinsk/electrician
     без index.html: "Доделай.ру — шабашка и подработка в Ярославле"   ← главная
     с index.html:   "Электромонтаж в Рыбинске: цены и исполнители"    ← верно

  /contacts
     без index.html: "Доделай.ру — шабашка и подработка в Ярославле"   ← главная
     с index.html:   "Контакты — Доделай.ру"                           ← верно

Так со всеми 303 страницами.


ЧТО НУЖНО

Чтобы при запросе /путь сервер сначала искал файл /путь/index.html в статике
и отдавал его, и только если файла нет — срабатывал SPA-fallback на корневой
index.html.

Сейчас fallback срабатывает всегда, не проверяя наличие статического файла.

В Caddy это примерно:
    try_files {path} {path}/index.html /index.html


ПОЧЕМУ ЭТО ВАЖНО

Поисковые роботы и сервисы аналитики ходят по обычным адресам, без /index.html.
Они видят на всех 303 страницах один и тот же заголовок, одно описание и один
canonical (https://dodelay.ru/). Из-за этого:

 - страницы не индексируются как отдельные;
 - проверка сайта показывает 27 дублей title, 27 дублей description
   и 25 неканонических адресов в sitemap.xml;
 - позиции по запросам не отслеживаются — везде определяется главная.

Сами страницы и мета-теги в сборке уникальны, проблема только в раздаче.


ДОПОЛНИТЕЛЬНО (по той же теме)

1. Не работает www-редирект.
   https://www.dodelay.ru/ не отвечает вообще (код 000).
   https://dodelay.ru/ работает нормально (200).
   Нужен редирект с www на основной домен.

2. Нет сжатия ответов.
   В ответе нет заголовка Content-Encoding даже при запросе
   с Accept-Encoding: gzip, br. Не сжимаются HTML, CSS и JS.
   Просьба включить gzip/brotli.


ТЕХНИЧЕСКИЕ ДЕТАЛИ

Сборка:            npm run build (vite build + пререндер)
Структура статики: dist/podrabotka/{город}/index.html
                   dist/podrabotka/{город}/{услуга}/index.html
                   dist/podrabotka/{город}/rayon/{район}/index.html
Всего страниц:     304 (включая главную)
Карта сайта:       https://dodelay.ru/sitemap.xml
Сервер в ответе:   Caddy + nginx
